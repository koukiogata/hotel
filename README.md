# 水の惑星 - ホテルプロデュース＆ホテル開発会社 Webサイト

## 概要
**水の惑星**は、ホテルプロデュースと開発を専門とする会社であり、「乾いた人生の旅に潤いをもたらす」というコンセプトでホテル事業を展開しています。このWebサイトは、同社の魅力や事業内容を伝えるために設計され、ビジネスのブランドイメージとコンセプトを反映したデザインが特徴です。

## 主な機能
- **事業内容の紹介**  
  ホテルプロデュース、ホテル開発に関するサービス内容や実績を紹介しています。

- **ビジュアル重視のデザイン**  
  ユーザーが「水の惑星」をイメージできるような、涼やかで透明感のあるビジュアルを採用しています。

- **スクロールアニメーション**  
  ユーザーエンゲージメントを高めるために、スクロールに応じて画像やテキストがフェードインする効果を実装しました。

- **レスポンシブ対応**  
  モバイルやタブレット、デスクトップでの閲覧を想定したレスポンシブデザインを採用しています。

## 使用技術
- **フロントエンド**: HTML, CSS (SCSS), JavaScript, Vue.js
- **アニメーション**: CSSアニメーション, JavaScript
- **スタイリング**: SCSSを使用し、モジュール化したスタイルシートでコードの可読性を向上
